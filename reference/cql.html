CQL Queries (COSMIC ORM)

Query holons on any provider with CQL v1: a bounded JSON query that WEB4 compiles natively for MongoDB, SQLite, Neo4j, blockchains and more.

Overview

CQL v1 is a JSON query description, not a text language. You post a JSON object to WEB4 and the server compiles it for the provider you name. A query can never contain executable C#, SQL or Cypher, so the same query is safe on every provider. CQL is the query layer of the COSMIC ORM.

RequirementDetail
AuthAuthorization: Bearer <JWT> of a signed-in avatar
Idempotency-KeyRequired header. Use a new value for each new query intent; re-sending the same key returns HTTP 409.
BodyJSON object, at most 32,768 bytes. Unknown members are rejected.

Query Kinds

Each kind has its own route and request shape (the Cql*V1Request models, with examples on WEB4's Swagger page).

RouteWhat it returns
POST /api/data/query-cqlMatching holons (filter, order, page)
POST /api/data/query-cql/indexedHolons found through a provider index
POST /api/data/query-cql/scalarOne value: count, any, min, max, sum, average
POST /api/data/query-cql/indexed/scalarA scalar over an index
POST /api/data/query-cql/projectionSelected fields only
POST /api/data/query-cql/projection/mixedFields and metadata paths together
POST /api/data/query-cql/groupedGrouped results with aggregates
POST /api/data/query-cql/setSet operations (union, intersect, except)
POST /api/data/query-cql/joinJoins between holon types
POST /api/data/query-cql/compositionSeveral steps composed into one query
POST /api/data/query-cql/federationOne query across several providers
GET /api/data/query-cql/providersProviders that accept CQL on this node

A Basic Query

json
{
  "provider": "MongoDBOASIS",
  "filters": [
    { "field": "Name", "scalar": "String", "operator": "Contains", "value": "coffee" }
  ],
  "orderBy": "Name",
  "descending": false,
  "skip": 0,
  "take": 10,
  "includeMetadata": false
}

A filter names a whitelisted field or a typed metadataPath (up to four segments), a scalar type (String, Integer, Boolean, Guid, DateTime, UInt64, Decimal, Double, Single), an operator (Equal, NotEqual, GreaterThan, GreaterThanOrEqual, LessThan, LessThanOrEqual, Contains, StartsWith, EndsWith, Exists, IsNull) and a value. filters are ANDed; anyOf is ORed; anyChildren and anyDescendants match holons by their children.

Calling It

bash
curl -X POST "https://api.web4.oasisomniverse.one/api/data/query-cql" \
  -H "Authorization: Bearer $OASIS_JWT" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d @query.json
javascript
import { OASISClient } from '@oasisomniverse/web4-api';

const oasis = new OASISClient({ baseUrl: 'https://api.web4.oasisomniverse.one' });
await oasis.auth.login({ username, password });

const { result } = await oasis.data.query({   // POST /api/data/query-cql
  provider: 'MongoDBOASIS',
  filters: [{ field: 'Name', scalar: 'String', operator: 'Contains', value: 'coffee' }],
  take: 10
});

From the STAR CLI, beam in first (avatar beamin), then run cql variants, cql example or cql run query --file query.json. The CLI sends a fresh Idempotency-Key on every run unless you pass --idempotency-key.

SQL-like Queries

POST /api/data/query-cql/sql takes { "query", "parameters"? }. WEB4 compiles the statement into the matching typed CQL request and runs it, with the same permissions, limits and results. Statements are read-only. Bind values with @name parameters instead of pasting them into the text. The request may be up to 16 KB and the statement up to 4,096 characters. The X-OASIS-CQL-Path response header names the typed endpoint that ran; invalid text returns 400 CQL_SQL_INVALID with the parser's message.

bash
curl -X POST "https://api.web4.oasisomniverse.one/api/data/query-cql/sql"   -H "Authorization: Bearer $OASIS_JWT"   -H "Idempotency-Key: $(uuidgen)"   -H "Content-Type: application/json"   -d '{"query":"SELECT Id, Name FROM MongoDBOASIS WHERE Version >= @min LIMIT 5","parameters":{"min":1}}'
javascript
const { result } = await oasis.data.sql({
  query: 'SELECT COUNT(*) AS Total FROM SQLLiteDBOASIS'
});

Free-text Queries

POST /api/data/query-cql/ask takes { "question", "execute"? }. WEB4 asks WEB6 to draft a statement from your question (this uses your WEB6 allowance), checks it with the same parser and runs it. Set execute to false to get { sql } back and review it first. When it runs, the X-OASIS-CQL-Text header holds the URL-encoded statement. A question that cannot be expressed returns 422 CQL_ASK_UNSUPPORTED; a WEB6 failure returns 502. Questions may be up to 1,000 characters.

bash
curl -X POST "https://api.web4.oasisomniverse.one/api/data/query-cql/ask"   -H "Authorization: Bearer $OASIS_JWT"   -H "Idempotency-Key: $(uuidgen)"   -H "Content-Type: application/json"   -d '{"question":"Show five active records from MongoDB ordered by name","execute":true}'
javascript
const draft = await oasis.data.ask({
  question: 'How many records are in SQLite?',
  execute: false
});
console.log(draft.result.sql);

Providers

MongoDB, SQLite and Neo4j run CQL natively on your own data, with atomic writes where HyperDrive needs them. In the hosted CQL sandbox more than 100 providers return real records, including the blockchain, IPFS, vector and time-series providers. Ask the node which it supports with GET /api/data/query-cql/providers.
