WEB4 CQL Sandbox

A browser playground for CQL: a demo avatar, live providers and tools to take a provider offline and watch HyperDrive fail over.

Overview

The sandbox runs on the WEB4 node at web4.oasisomniverse.one. It signs you in as a demo avatar, lets you run every CQL query kind against live providers, and shows how HyperDrive behaves when a provider goes offline. It is public and shared: put nothing private in it.

Start a Session

POST/api/sandbox/session

Creates or resumes a demo avatar and returns its access token. The refresh token is set as an HttpOnly, Secure, SameSite=Lax cookie, the same as a normal sign-in. The page keeps the bearer in memory and renews it with POST /api/avatar/refresh-token before it expires.

Take Providers Offline

POST/api/sandbox/providers/{providerType}/offline
POST/api/sandbox/providers/{providerType}/online

Marks a provider offline for your session so you can see HyperDrive route reads and writes to the next provider, then brings it back.

Faults and Refusals

GET/api/sandbox/faults
GET/api/sandbox/refusals

Lists the faults HyperDrive handled and the requests the node refused (for example a query over the size limit or a reused Idempotency-Key), so you can see why something did not run.

Native Demo

POST/api/sandbox/native-demo

Runs the built-in native-provider demo: it writes sample holons and queries them back with CQL on the providers that store natively.
