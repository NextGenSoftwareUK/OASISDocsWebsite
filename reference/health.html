Health Checks

Liveness endpoints for every OASIS API, WEB4 to WEB10.

Endpoints

APIEndpointHealthy response
WEB4 OASIS APIGET https://api.web4.oasisomniverse.one/api/healthhealthy
WEB5 STAR APIGET https://api.starnet.oasisomniverse.one/api/healthhealthy
WEB6 AI APIGET https://api.web6.oasisomniverse.one/v1/healthok
WEB7 to WEB10GET https://api.web7.oasisomniverse.one/health (and web8, web9, web10)healthy

None of these need a token. Dev hosts add a dev. prefix, for example https://dev.api.web4.oasisomniverse.one/api/health.

From the SDKs

javascript
const web7 = new Web7Client({ baseUrl: 'https://api.web7.oasisomniverse.one' });
const { isError, result } = await web7.health();   // result.status === 'healthy'

Provider Health

For the health of the storage providers behind WEB4, use HyperDrive's status and metrics: GET /api/hyperdrive/status and GET /api/hyperdrive/metrics. See HyperDrive.
