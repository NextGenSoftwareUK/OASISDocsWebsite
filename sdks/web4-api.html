WEB4 JS SDK

Full module reference for @oasisomniverse/web4-api — the isomorphic JavaScript SDK for the OASIS WEB4 API. Works in Node 18+ and all modern browsers.

Installation

terminal
npm install @oasisomniverse/web4-api

Initialisation

javascript
import { OASISClient } from '@oasisomniverse/web4-api';

const oasis = new OASISClient({
  baseUrl: 'https://api.web4.oasisomniverse.one'  // or your ONODE URL
});

// Sign in (stores the JWT for later calls), or set one you already have:
await oasis.auth.login({ username, password });
oasis.setToken(jwtToken, { avatarId, username });

Auth Module — oasis.auth

  • auth.register(params)Register a new avatar. Returns { result, isError, message }.
  • auth.authenticate(params)Authenticate and receive a JWT token. Sets oasis.token automatically on success.
  • auth.forgotPassword(email)Send password-reset email.
  • auth.resetPassword(params)Reset password using the emailed token.

Avatar Module — oasis.avatar

  • avatar.get(id)Fetch a single avatar by ID.
  • avatar.getAll()Fetch all avatars. Admin only.
  • avatar.update(id, params)Update avatar fields.
  • avatar.delete(id)Soft-delete avatar. Admin only.
  • avatar.search(query)Search avatars by username, email or title.

Karma Module — oasis.karma

  • karma.addKarmaToAvatar(params)Award karma. See Karma API for params.
  • karma.removeKarmaFromAvatar(params)Deduct karma.
  • karma.getKarmaForAvatar(id)Full karma history and total.

Data Module — oasis.data

  • data.saveHolon(holon, providerType?)Persist a holon object. Provider optional.
  • data.loadHolon(id, providerType?)Load a holon by ID.
  • data.deleteHolon(id, providerType?)Delete a holon.
  • data.searchHolons(query)Full-text search across holons.

NFT & Wallet Module — oasis.nft

  • nft.mintNFT(params)Mint a new NFT on the configured chain.
  • nft.transferNFT(params)Transfer an NFT between avatars.
  • nft.getNFTsForAvatar(id)List all NFTs owned by an avatar.
  • nft.getBalance(id, chainType?)Get wallet balance across chains.

Maps, recorded routes and shared places

The generated source client exposes the methods below. This reference describes qualified WEB4 2.0.18 source; npm 2.0.17 and deployed server revisions have separate release gates. The new cross-app attribution field is not yet accepted on a hosted deployment.

  • map.list({offset, limit})List the avatar's route summaries without eagerly fetching geometry.
  • map.getRoutesById({id})Read permitted route geometry and the revisions required for conditional updates.
  • map.create(writeIntent)Save a recorded route using its operation identity and expected revisions.
  • map.updateAccess({id, ...writeIntent})Conditionally change name or public access using the returned revisions.
  • places.nearby({category, latitude, longitude})Query the configured real-world catalogue.
  • places.observe(observation)Report a fresh physical-place observation for the authenticated avatar.
  • places.presence()Read active physical-place visits.
  • places.visits({offset, limit})Read the avatar's durable cross-app visit and karma history.

An observation contains a stable GUID id, catalogue placeId, actual latitude/longitude, fresh UTC observedUtc and optional sourceApp. The label is 1–256 characters without surrounding whitespace or control characters. It is reported metadata, not authenticated application identity. Legacy requests without it retain Our World attribution.

Arrival within 50m earns 100 karma on the first physical-place visit and 50 on a return after departure at 100m or farther. Changing app labels does not reset eligibility or create another active visit. A successful departure or already-active observation can return no new visit. Check isError and isWarning, not HTTP status alone. Visit pages contain items, total and optional nextOffset; stop on absent/null continuation.

OPORTAL reads the same visit ledger as Our World and other apps. GeoNFTs, WEB5 hotspots and quest/objective locations remain authoritative domain records layered on the map. A route import or source label does not prove walked distance or earn a place reward. MapLibre camera controls are separate from legacy server renderer operations requiring a compatible map runtime.

HyperDrive Module — oasis.hyperdrive

  • hyperdrive.getProviderHealth()Get health scores for all registered providers.
  • hyperdrive.setDefaultProvider(providerType)Change the default provider at runtime.
  • hyperdrive.replicateToProvider(targetType)Trigger a manual replication to a provider.
