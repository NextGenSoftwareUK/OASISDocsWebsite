WEB7 to WEB10 SDKs

JavaScript clients for the WEB7 Symbiosis, WEB8, WEB9 and WEB10 APIs.

Packages

PackageClientProduction host
@oasisomniverse/web7-apiWeb7Clienthttps://api.web7.oasisomniverse.one
@oasisomniverse/web8-apiWeb8Clienthttps://api.web8.oasisomniverse.one
@oasisomniverse/web9-apiWeb9Clienthttps://api.web9.oasisomniverse.one
@oasisomniverse/web10-apiWeb10Clienthttps://api.web10.oasisomniverse.one

Dev hosts add a dev. prefix.

Usage

javascript
import { Web7Client } from '@oasisomniverse/web7-api';

const web7 = new Web7Client({ baseUrl: 'https://api.web7.oasisomniverse.one' });
web7.setToken(jwtFromWeb4);   // these layers reuse the WEB4 OASIS identity

const up = await web7.health();
const session = await web7.symbiosis.startSession({ avatarId, consentGranted: true });

Each controller on the API is a lowerCamel property on the client (for WEB7: symbiosis and collectiveConsciousness). Every client also has health(), which needs no token.

Metering

Calls are metered against the caller's subscription through WEB4. See Subscription & Usage.
