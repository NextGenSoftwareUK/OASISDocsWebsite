SDK

WEB6 AI SDK

@oasisomniverse/web6-api: completions, agents, holonic memory, FAHRN reasoning, A2A networking and more from JavaScript.

Installation

terminal
npm install @oasisomniverse/web6-api

Initialisation

javascript
import { Web6Client } from '@oasisomniverse/web6-api';

const ai = new Web6Client({ baseUrl: 'https://api.web6.oasisomniverse.one' });
ai.setToken(jwtFromWeb4);   // WEB6 uses the same OASIS identity as WEB4

Modules

PropertyWhat it does
ai.completionChat and text completions, streaming
ai.agentServer-side agent runs (run, feedback)
ai.holonicMemoryMemory stored on holons: search, semantic search, documents, propagation
ai.holonicBraid, ai.reasoningNetwork, ai.fahrnSolveMulti-model reasoning and FAHRN debate
ai.a2AAgent-to-agent network: cards, messages, tasks, payments, JSON-RPC
ai.schedules, ai.channelsScheduled agent runs and channel webhooks
ai.orchestratorCrewAI, AutoGen and LangGraph workflows
ai.images, ai.speech, ai.video, ai.embedding, ai.rerankMedia and retrieval building blocks
ai.usage, ai.estimateYour WEB6 usage and cost estimates

Every method takes one args object: route tokens such as {holonId} are taken from it, and the rest is sent as the query string (GET/DELETE) or JSON body (POST/PUT). The package README lists all 125 methods.

MCP Server

The same capabilities are available to AI assistants through @oasisomniverse/mcp-server, which exposes the WEB4 to WEB10 APIs as MCP tools.
